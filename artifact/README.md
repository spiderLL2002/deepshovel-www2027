# DeepShovel 2.0 Artifacts

This directory contains the demonstration walkthrough, evaluation data, argument-expansion verification, and GP15 research package for the WWW 2027 demonstration paper ([`paper/main.pdf`](../paper/main.pdf)).

## Contents

- [Demonstration walkthrough](live-demo/README.md): step-by-step guide, captured screens, and offline F2/Fiskegrav/GP15 examples.
- [Evaluation package](benchmark/README.md): retrieval benchmark (430 questions), argument-comparison test (264 cases), online runs (175 queries), and source audit.
- [Argument expansion](arguments/README.md): F2 condition-checking graph and dependency-expansion verifier (`second-case/` holds the Asmari source PDF and graph).
- [GP15 research package](gp15/README.md): public GEOTRACES GP15 datasets, frozen protocol, and ten-stage analysis pipeline.
- [Research trace](research-trace/README.md): eight-round agent screening records (48 candidate questions) and claim-to-source lineage.

See the [root README](../README.md#reproduce-the-evaluation-and-gp15-research) to reproduce all reported numbers and verification checks.
